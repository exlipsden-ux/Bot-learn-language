Tatar Learn Bot

Telegram-бот для изучения и пополнения словарного запаса татарского языка. 
Бот построен по принципу **флеш-карточек с системой самооценки**: он предлагает слова из базы (~50 000 слов), а пользователь сам оценивает свои знания, что позволяет гибко настраивать процесс обучения под себя.

## ✨ Возможности

* 🔄 **Три направления обучения:** С татарского на русский, с русского на татарский или в смешанном режиме.
* 🧠 **Умная система пулов:** Бот подает слова порциями по 10 штук, чтобы не перегружать пользователя.
* 📊 **Система самооценки:** 
  * 👎 *Не знаю* — слово останется в пуле и повторится.
  * 🤔 *Почти знаю* — слово повторится позже.
  * 👍 *Выучил!* — слово отправляется в архив выученных, а в пул добавляется новое.
* 📚 **Повторение:** Возможность в любой момент повторить уже выученные слова.
* 📈 **Личная статистика:** Отслеживание прогресса (выучено, в процессе, всего).
* 🛠 **Админ-панель:** Глобальная статистика по пользователям и массовая рассылка сообщений.

## 🛠 Технологический стек

* **Python 3.10+**
* **Aiogram 3.x** — асинхронный фреймворк для Telegram Bot API (используются FSM, Router, Middleware).
* **JSON** — для хранения словаря и персистентности данных пользователей.

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ваш_логин/tatar-learn-bot.git
cd tatar-learn-bot
```

### 2. Установка зависимостей
```bash
pip install aiogram
```

### 3. Подготовка словаря
Боту требуется файл `dictionary.json` в корне директории. 
**Формат словаря:**
```json
{
  "татарское_слово": ["перевод_1", "перевод_2"],
  "исәнмесез": ["здравствуйте", "приветствую"],
  "рәхмәт": ["спасибо"]
}
```
*(Примечание: файл `dictionary.json` не добавлен в репозиторий из-за его размера. Вам нужно подготовить его самостоятельно или загрузить свою базу).*

### 4. Настройка конфигурации
Откройте файл `tat_learn.py` и заполните константы в блоке `=== КОНФИГ ===`:
```python
BOT_TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER"
ADMIN_ID = ВАШ_TELEGRAM_ID # Числовой ID
```

### 5. Запуск
```bash
python tat_learn.py
```

## 📱 Использование

После запуска бота отправьте ему команду `/start`. 
Далее используйте удобную Reply-клавиатуру:
* **🔄 Начать обучение** — старт сессии и выбор направления.
* **📊 Моя статистика** — просмотр прогресса.
* **📚 Повторить выученные** — режим повторения.

## ⚙️ Команды для Администратора

Доступны только пользователю, чей ID указан в `ADMIN_ID`:

| Команда | Описание |
| :--- | :--- |
| `/stats` | Показывает общее количество зарегистрированных пользователей в боте. |
| `/broadcast <текст>` | Отправляет указанное сообщение всем пользователям бота (рассылка). |

## 🗂 Структура данных пользователей
Данные каждого пользователя сохраняются в `user_data.json` и имеют следующую структуру:
```json
{
  "user_id": {
    "direction": "tt->ru",       // Выбранное направление
    "learned": [],               // Список выученных пар
    "pool": [],                  // Текущие 10 слов для изучения
    "available_words": []        // Слова из словаря, которые еще не были в пуле
  }
}
```
